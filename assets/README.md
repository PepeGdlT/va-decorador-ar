# Recursos para la demo fotográfica

- `landscape-met.jpg`: [Wheat Field with Cypresses, Vincent van Gogh](https://www.metmuseum.org/art/collection/search/436535).
- `carpet-met.jpg`: [Carpet, The Metropolitan Museum of Art](https://www.metmuseum.org/art/collection/search/446954).

Las dos imágenes proceden del [programa Open Access del Met (CC0)](https://www.metmuseum.org/hubs/open-access). El programa recorta los márgenes de las reproducciones, enmarca la pintura y rota la alfombra para presentarla en horizontal.
